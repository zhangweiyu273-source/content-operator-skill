# 常见问题

## 工具会得到我的密码吗？

不会。密码、扫码和验证码都在平台页面中由你操作，工具没有密码收集功能。

## 为什么显示未连接？

点击「启动专属浏览器」。如果已经打开但仍未连接，关闭所有由本工具打开的专属 Edge 窗口，再重新点击。不要手工修改 browser_profile。

## 为什么无法确认账号？

请确认已登录、打开的是创作者后台、页面能看到昵称和稳定账号 ID。工具不会只凭昵称猜测身份。

## 为什么同步被中止？

验证码、风控、权限不足、账号不一致或页面结构变化都会中止。先根据界面错误码处理。工具不会绕过这些限制。

## 为什么某些数字是 null？

`null` 表示当前页面没有可靠展示该字段。工具不会用 0 或估算值填充。

## 怎么备份？

源码模式可运行 `npm run backup`；便携版可复制 `workspace/backups` 中生成的数据库文件。浏览器 Profile 不建议作为数据备份分享。

## 怎么删除全部本地数据？

先关闭工具黑色窗口和专属浏览器，再删除本工具目录下的 `workspace`。这会删除账号绑定、数据库、快照、导出、备份和专属登录状态，通常无法恢复。另存到其他位置的 ZIP 需另行删除。

## 能同步多个账号吗？

V1 不做批量账号。每个账号应使用完全独立的解压目录和 workspace，避免混写。

## 能自动点赞、评论或发布吗？

不能，也不会加入这些功能。本工具只整理用户主动打开、自己有权限查看的数据。
