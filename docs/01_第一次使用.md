# 第一次使用

准备一台 Windows 11 电脑，并确认电脑上能正常使用 Microsoft Edge。

1. 解压便携包。不要直接在 ZIP 里运行。
2. 双击 `启动内容运营数据同步工具.cmd`。黑色窗口是本地工具，请在使用期间保持打开。
3. 打开界面显示的本地地址 `http://127.0.0.1:31876`。
4. 点击「启动专属浏览器」。Edge 会打开一个独立窗口。
5. 在这个窗口里登录你自己的账号。扫码、密码和验证码都由你本人处理。
6. 登录完成后回到工具，检查并确认账号。
7. 进入需要的后台页面，再点击同步。
8. 查看本地数据，确认无误后导出。

第一次启动会在工具目录建立 `workspace`。数据不会自动上传。以后仍从同一个解压目录启动，专属浏览器才能继续使用原有登录状态和历史数据。

如果 Windows 防火墙询问是否允许网络访问，请取消公共网络权限；本工具只需要本机地址。不要把整个 workspace 发给别人。
