# 登录自己的账号

点击「启动专属浏览器」后，只在新打开的专属 Edge 窗口登录。

账号密码直接输入平台页面，工具没有密码输入框，也不会读取密码。扫码和验证码必须由你本人完成。如果页面显示安全验证、登录异常或风控提示，先在浏览器里人工处理；工具不会代做或绕过。

登录成功后：

1. 打开你有权限查看的创作者后台页面。
2. 回到工具点击「检查登录账号」。
3. 核对昵称、账号 ID 和页面地址。
4. 确认无误后点击「确认并绑定此账号」。

绑定后，每次同步仍会重新读取当前账号 ID。如果换了账号，工具会显示 `ACCOUNT_MISMATCH` 并中止。V1 不允许把另一个账号写进当前工作区；需要切换时，应先备份和导出原账号数据，再建立完全独立的工具目录。

专属登录状态位于 `workspace/browser_profile`。不要复制或分享此目录。
