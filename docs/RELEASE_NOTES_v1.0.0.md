# Content Operator Skill v1.0.0

首次公开版本。

包含两部分：

1. 内容运营 Skill Public V1
   - 账号定位
   - 历史数据分析
   - 选题池
   - 热点筛选
   - 内容生成
   - 发布后复盘

2. Local Data Connector for Windows
   - 用户本人手动登录
   - 本地同步本人有权查看的账号数据
   - 本地 SQLite 存储和历史 Snapshot
   - 导出给 Public Skill
   - 不上传 Cookie、Token 或密码
   - 不自动点赞、评论、关注或发布

Windows Connector 已完成正式实机验收。
