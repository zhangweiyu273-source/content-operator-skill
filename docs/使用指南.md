# Content Operator Skill 使用指南

## 使用 Public Skill

1. 从 GitHub Releases 下载 `content-operator-skill-public-v1.zip` 并解压。
2. 将其中的 `SKILL.md`、`README.md` 和 Schema 导入支持 Skill 或文件读取的桌面智能体。
3. 发送“初始化我的内容账号”。
4. 主动提供账号主页截图、后台截图、历史笔记或导出的数据包。
5. 让 Skill 分析定位、建立账号数据基准和选题池。
6. 发布内容后补充新数据，继续复盘和规划下一轮内容。

用户可以只使用 Public Skill，不必安装数据同步工具。

## 使用 Windows 数据同步工具

1. 下载 `content-operator-local-data-connector-windows-x64-v1.0.0.zip`。
2. 完整解压 ZIP，双击 `启动内容运营数据同步工具.cmd`。
3. 在本地页面点击“启动专属浏览器”。
4. 在专属 Edge 窗口中由本人完成登录、扫码、密码和验证码。
5. 回到工具检查当前账号，核对后确认绑定。
6. 在专属浏览器打开对应后台页面，再点击同步账号信息、历史笔记、当前笔记或阶段数据。
7. 查看本地数据，点击导出，将生成的数据包交给 Public Skill。

## 数据位置

Connector 的数据默认位于解压目录中的 `workspace/`：

- `account_identity.json`：用户确认的账号身份
- `content_operator.db`：本地 SQLite 数据库
- `browser_profile/`：专属浏览器登录状态
- `snapshots/`：历史快照
- `exports/`：给 Public Skill 的导出包
- `backups/`：本地备份

不要分享整个 `workspace/` 或 `browser_profile/`。

## 隐私与安全

- 开发者不需要用户的账号密码。
- 用户本人在平台页面完成登录。
- Cookie、Token、密码、数据库和 Browser Profile 不进入导出包。
- 工具不自动点赞、评论、关注、私信或发布。
- 工具不绕过验证码、风控或访问权限。

## 完整删除本地数据

关闭工具和专属浏览器后，删除解压目录中的 `workspace/` 即可移除本工具保存的数据和专属登录状态。另行复制的导出包与备份需要在对应位置单独删除。
