# 同步账号数据

同步前确认专属浏览器仍开着，并停留在正确的后台页面。每次点击只运行一次，不会在后台持续抓取。

- 「同步账号信息」：在账号主页或概览页使用，读取昵称、账号 ID、简介及页面实际显示的账号数字。
- 「同步历史笔记」：在已发布内容列表页使用。工具有限滚动加载，默认最多 20 轮或 200 条，连续两轮没有新内容就停止。
- 「同步当前笔记」：先在专属浏览器打开一篇笔记的数据页，再点击此按钮。
- 「同步阶段数据」：在显示近 7 天、近 30 天或趋势数据的页面使用。

结果为 PASS 表示本次数据通过基础校验；ATTENTION 表示部分字段需要检查。页面没展示的数字是 `null`，这和数值 0 不同。

出现 `USER_ACTION_REQUIRED` 时，按界面提示返回浏览器处理。出现 `PAGE_SCHEMA_CHANGED` 时，不要连续重试；确认页面正确后仍失败，说明页面结构可能更新，需要升级 selectors。

每次同步都会创建运行记录和新 Snapshot。相同笔记 ID 更新主记录，不重复创建；历史指标快照继续保留。
