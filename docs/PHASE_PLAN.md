# 阶段约束

PHASE 0 仅环境、基线接口、独立 Git、数据目录、Profile 路径与安全文档。完成后停止，等待用户下一条指令。

后续依次为：1 Workspace + SQLite + Schema；2 专属浏览器；3 身份确认；4 账号 Collector；5 历史笔记；6 单篇数据；7 快照和去重时间序列；8 Public Skill 导出适配；9 基础 UI；10 异常保护；11 完整测试；12 新用户教程；13 Windows 免安装 ZIP；14 干净 Windows 验收。核心稳定后才考虑 15 EXE 安装包。

本阶段不得实现数据库、页面读取、浏览器启动、UI、真实数据示例、导出或打包。后续教程预留 01_第一次使用.md、02_登录自己的账号.md、03_同步账号数据.md、04_导出给Skill.md、05_常见问题.md，至 PHASE 12 再编写真实操作教程。
