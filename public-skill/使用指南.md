# 内容运营 Skill Public V1 使用指南

1. 将本目录中的 `SKILL.md`、`README.md` 和 `PUBLIC_V1_DATA_SCHEMA.json` 导入支持 Skill 或文件读取的桌面智能体。
2. 发送“初始化我的内容账号”。
3. 主动提供账号主页截图、后台截图、历史笔记、CSV、XLSX、JSON，或 Local Data Connector 导出的数据包。
4. 让 Skill 分析当前定位和历史表现，建立账号自己的数据基准与选题池。
5. 选择选题并生成标题、封面文案、正文和 CTA。
6. 由用户本人发布内容。发布后补充新数据，让 Skill 复盘并给出下一轮建议。

Public Skill 不需要账号密码，不处理验证码，不绕过风控，不自动点赞、评论、关注或发布。
