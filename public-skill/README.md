# 内容运营 Skill Public V1

一个面向个人内容创作者的长期运营 Skill。

它不是单纯的“AI 写文案”，而是围绕：

**数据 → 定位 → 选题 → 内容 → 复盘**

建立持续运营闭环。

## 能做什么

- 建立账号档案
- 导入后台截图 / Excel / 历史笔记
- 分析实际定位
- 建立账号自己的数据基准
- 找出历史高表现内容
- 建立长期选题池
- 筛选热点
- 做选题分发门禁
- 生成标题 / 封面 / 正文 / CTA
- 发布后根据新数据复盘
- 形成下一轮内容实验

## Public V1 的数据来源

Public V1 使用用户主动提供的数据：

- 账号主页截图
- 创作者后台截图
- Excel / CSV / JSON
- 历史笔记
- 用户主动提供的搜索结果
- 公开互联网资料

账号密码不需要交给 Skill。

## 第一次怎么用

最简单的方式：

1. 把账号主页截图、后台截图、几篇历史笔记发给智能体。
2. 输入：
   > 初始化我的内容账号
3. 再输入：
   > 分析我现在的定位，并找出最值得继续做的内容
4. 之后可以持续使用：
   > 今天我应该做什么？
   > 给我今天最值得测试的 5 个选题
   > 写第 2 个
   > 更新这篇发布后的数据并复盘

## 设计思想

Public V1 不用统一的“爆款标准”评价所有账号。

它优先建立账号自己的近期基准，然后寻找相对高表现内容。

热点只是一个来源。真正的选题判断是：

**热点 / 历史表现 / 长期用户问题 / 事件节点**
×
**账号定位**
×
**目标用户**
×
**真实素材**

## 数据隐私

建议账号资料保存在用户自己的工作区或本地目录。

Public V1 不要求用户提供账号密码，也不包含验证码绕过、访问限制绕过、自动点赞、自动评论或自动发布。

## 可选的本地数据同步工具

本仓库同时提供 `Local Data Connector for Windows`。用户可以在专属浏览器中自行登录，将本人有权查看的账号和笔记数据保存在本地，再导出给 Public Skill。连接器不会导出 Cookie、Token、密码或 Browser Profile，也不会自动点赞、评论、关注或发布。
